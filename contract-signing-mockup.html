지금 상태 — 실제 화면을 확인해보니 체결·종료 계약 행 자체는 이미 표시됩니다(CONTRACT_STATUS_LABEL 에 전부 정의됨). 문제는 CONTRACT_STATUS_FILTERS 가 검토 4단계만 담고 있어 필터로 좁힐 방법이 없다는 것. 칩만 늘리면 해결됩니다.
남는 것 — 검토를 거친 계약은 마지막에 "실제로 체결됐다"를 찍을 사람이 필요합니다. 실제 화면을 확인해보니 체결 진행 상태에서 결재 현황 패널은 "체결 품의의 결재가 진행 중입니다." 안내만 띄우고, signing → signed 로 넘길 액션이 없습니다.

  • 권한 sealManager — contracts.authz.ts 에 이미 예외 처리되어 있음
  • 조건: 결재선 전원 승인 후에만 활성화
  • 모달에서 서명본 + 체결일을 받아 한 번에 처리 (View 1 체결 모드와 동일 입력)
