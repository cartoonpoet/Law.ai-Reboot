# 계약 갱신·해지·만료 관리 설계

- 날짜: 2026-09-16
- 시안: https://claude.ai/code/artifact/a7aeac29-2e30-4baa-9827-36fae5302ab4 (A·B·C 모두 채택)
- 사용자 결정
  - A(기존 계약에서 바로), B(새 요청으로), C(만료 예정 별도 메뉴) 전부 만든다.
  - C 에 AI 가 계약서에서 자동갱신 조항·해지 통지 기한을 뽑아 보여주는 것까지 이번에 넣는다(요청자 AI 연동 비용).
  - 갱신 계약이 체결되면 원 계약은 **즉시** "계약 종료(갱신됨)"로 바꾼다.

## 배경

체결 완료 → 계약 이행 → 계약 종료 버튼과 만료 90·30·7일 전 알림은 있다. 요청 폼의 "변경·해지" 단계는 원 계약을
관련 문서로 연결만 하고, 새 계약이 체결돼도 원 계약은 그대로 남는다. 계약이 왜 끝났는지(만료·갱신·해지)도 기록되지 않는다.

## 데이터

`Contract` 에 추가(Prisma 마이그레이션 + ERD 반영):

| 필드 | 타입 | 뜻 |
| --- | --- | --- |
| `closedReason` | enum `ContractClosedReason?` = `completed`·`expired`·`renewed`·`terminated` | 종료 사유. 종료 전엔 null |
| `closedAt` | `DateTime?` | 실제 종료일(해지는 해지일, 갱신은 갱신 계약 체결일) |
| `closedNote` | `String?` | 해지 사유·메모 등 사람이 남긴 설명 |
| `originContractId` | `String?` (자기 참조 FK, index) | 갱신·변경·해지 요청이 가리키는 원 계약 |

`details.stage` 는 `"new" | "renew" | "change" | "terminate"` 로 넓힌다. 기존 `"change"`(변경·해지)는 "변경"으로 읽는다.

자동갱신 조항 추출 결과는 기존 `AiAnalysis` 에 kind `renewalTerms` 로 저장한다(스키마 변경 없음).

## 1단계 — 종료 사유 + A 중도 해지

- `updateStatus` 로 `closed` 가 되면 `closedReason = completed`(C 의 "만료로 종료"는 `expired` 를 넘긴다), `closedAt = 오늘`.
- 새 RPC `contract.terminate` / `POST /contracts/:id/terminate`
  - 대상: 체결 완료·계약 이행. 권한: 체결 이후 진행 권한(법무팀·담당자·요청자)과 같다.
  - 입력: 해지일, 사유(합의 해지·상대방 귀책·당사 사정·기타), 메모, 해지 합의서·통지서 파일(이 계약에 새로 첨부한 파일, 필수).
  - 결과: `closed` + `terminated` + `closedAt = 해지일` + `closedNote`, 파일 설명에 "해지 합의서·통지서" 표시, 감사 기록.
- 화면: 체결 완료 "이행 시작 / 중도 해지", 계약 이행 "계약 종료 / 중도 해지". 종료된 계약 패널에 종료 사유·종료일·메모.

## 2단계 — B 요청 흐름 + A 갱신 요청

- 요청 폼 계약 단계: 신규 · 갱신 · 변경 · 해지. 갱신·변경·해지는 원 계약(체결 완료·계약 이행 계약)을 고르면 `originContractId` 저장.
- 갱신은 원 계약 내용(상대 계약자·분류·보안 등급·참조·금액·목적)을 채워 준다. 계약명은 "(갱신)"을 붙여 제안, 기간은 원 계약 만료 다음 날부터 같은 길이로 제안.
- A "갱신 요청" 버튼 → `/contract/request?origin=<id>&stage=renew` 로 같은 폼을 연다.
- 갱신·해지 계약이 체결되면(체결 처리·체결 완료 등록) 원 계약이 아직 체결 완료·계약 이행이면 같은 트랜잭션 뒤 즉시 `closed` + `renewed`/`terminated` + `closedAt = 체결일` + 감사 기록. 변경 계약은 원 계약을 닫지 않는다.
- 상세 화면: 새 계약엔 "원 계약" 카드, 원 계약엔 "갱신 계약 / 해지 계약" 링크.

## 3단계 — C 만료 관리 메뉴 + AI 자동갱신 조항

- 사이드바 "계약 관리 › 만료 관리" (`/contract/expiring`).
- 탭: 7일 안 · 30일 안 · 90일 안 · 지난 만료(기간이 지났는데 아직 체결 완료·계약 이행인 계약).
- 표: D-day, 계약(이름·관리번호·담당), 상대방, AI 판단, 결정 버튼(갱신 요청 → B, 만료로 종료, 중도 해지 → A 모달).
- AI 판단 `renewalTerms`: `{ autoRenewal, renewalPeriod, noticeDays, noticeDeadline, clause, summary }`.
  - 체결 처리·체결 완료 등록 때 요청자 AI 연동으로 백그라운드 추출.
  - 아직 없는 계약은 메뉴에서 "AI로 읽기" 버튼으로 한 건씩 추출(한꺼번에 돌려 비용이 튀지 않게).
